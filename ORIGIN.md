# Source provenance

This project starts an independent development history under the name `app-cuu-ho`.

- Original repository: https://github.com/DUT-AI/rescue-map.git
- Original checkout commit: `12b41731397e2e1c642b680c496f326205fa27a4`
- Imported from the current working tree, including local source changes.
- Original attribution and notices in source files are retained.
- No project-wide license file was present in the source snapshot; this import does not assign a new license to upstream code.
- Environment secrets, PostgreSQL runtime data, backups, dependencies and build outputs are excluded from Git.
- Embedded API credentials in the imported notebook were replaced with placeholders.
- Git paths differing only in letter case were consolidated to the actual Windows working file.

Local `.env` settings were copied for local use only and must remain ignored by Git. PostgreSQL data was not copied.
